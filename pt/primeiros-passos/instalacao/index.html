Instalação

Instale o SDK da infinity6 e configure sua chave de API.

1 min de leitura

Nesta página você prepara o ambiente para usar a plataforma infinity6.

Requisitos

Node.js 18 ou superior e uma conta com acesso ao Console.

Instale o SDK

bash
npm install @infinity6/sdk

Configure a chave de API

Guarde a chave em uma variável de ambiente — nunca no código-fonte.

bash
export INFINITY6_API_KEY="sk_live_..."

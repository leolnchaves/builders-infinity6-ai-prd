Primeiros passos

Primeira chamada

Execute seu primeiro agente e leia a resposta de decisão.

1 min de leitura

Com o SDK instalado, faça sua primeira chamada a um agente.

Usando o SDK

typescript
import { Infinity6 } from "@infinity6/sdk";

const i6 = new Infinity6({ apiKey: process.env.INFINITY6_API_KEY });

const response = await i6.agents.run({
  agent: "decision-analyst",
  input: "Qual canal priorizar no próximo trimestre?",
});

console.log(response.output);

Usando HTTP

bash
curl https://api.infinity6.ai/v1/agents/run \
  -H "Authorization: Bearer $INFINITY6_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"agent": "decision-analyst", "input": "..."}'

Entendendo a resposta

A resposta traz o texto final em output e o identificador da execução em id.

json
{ "id": "run_123", "status": "completed", "output": "..." }

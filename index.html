EXEMPLO RÁPIDO

Da ideia à primeira execução

Instale o SDK, configure sua chave e execute um agente com poucas linhas.

quickstart.ts
import { Infinity6 } from "@infinity6/sdk";

const i6 = new Infinity6({
  apiKey: process.env.INFINITY6_API_KEY
});

const response = await i6.agents.run({
  agent: "decision-analyst",
  input: "Analise o cenário e recomende a melhor ação"
});

console.log(response.output);
Compatível com Node.js 20+ e TypeScript

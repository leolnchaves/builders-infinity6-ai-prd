Verificando a sessão

Leia o usuário atual da sessão com o SDK web.

1 min de leitura

O SDK oferece duas formas de olhar a sessão.

Consultando o usuário

html
<script type="module">
  const sdk = new window.I6Sdk();
  const user = await sdk.auth().user();
  console.log(user);
</script>

sdk.auth().user() consulta api/auth/me na plataforma.

Exigindo a sessão

html
<script type="module">
  async function main() {
    const sdk = new window.I6Sdk();
    const user = await sdk.auth().requireUser();
    if (!user) return;
    // a partir daqui há sessão ativa
  }
  main();
</script>

requireUser() encaminha o navegador ao login quando não há sessão ativa. Use essa forma ao carregar a página, antes de qualquer ação do usuário.

Referência completa: auth().

Flujo de login

Cómo el SDK construye la URL de login y redirige el navegador.

1 min de lectura

Cuando no hay sesión activa, el SDK envía el navegador al login de la plataforma.

La URL construida por el SDK

text
{baseUrl}/api/decsuite/auth/login?backurl=<url actual codificada>

El SDK informa la página actual en backurl para que la plataforma pueda usarla en el retorno.

Hechos declarados

  • El SDK solo construye la URL de login y redirige el navegador. Lo que la plataforma hace con backurl después del login lo define ella.
  • Cuando la página se carga con sesión activa, requireUser() devuelve el perfil del usuario.

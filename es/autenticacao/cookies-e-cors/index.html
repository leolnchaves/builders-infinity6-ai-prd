Cookies y CORS

Requisitos de cookie y CORS para que la sesión funcione entre orígenes.

1 min de lectura

La sesión del SDK web depende de una cookie definida por la plataforma y de una configuración de CORS que acepte credenciales.

La cookie de sesión

La cookie la define la plataforma con SameSite=None; Secure. Por eso tu página debe servirse por HTTPS.

Envío de credenciales

Las llamadas del SDK a la API de la plataforma usan credentials: "include".

CORS

La plataforma responde con Access-Control-Allow-Credentials: true para los orígenes habilitados. Tu origen debe estar entre ellos.

Envío del archivo

El envío del archivo a la dirección firmada no pasa por esta configuración de credenciales.
